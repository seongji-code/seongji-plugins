# 다국어 화면 + 목업 합성

$ARGUMENTS

## 이 스킬이 하는 일

이미지 2장을 받는다.
1. **화면 이미지** — 다국어로 바꿀 핸드폰 화면 (스크린샷)
2. **사진** — 그 화면을 넣을 배경 사진 (폰을 든 손, 책상 위 등)

결과는 `<결과폴더>/YYYYMMDD/` 에 **평평하게** 저장한다. 하위 폴더로 나누지 않는다.

`<결과폴더>` 는 이 순서로 정한다.
1. 환경변수 `CREATE_WALLPAPER_OUT`
2. `~/Desktop/홍보` 가 있으면 거기
3. 둘 다 없으면 지금 작업 폴더

```
<결과폴더>/20260908/
  화면_ko.png  화면_ja.png  화면_zh-TW.png  화면_ms.png
  화면_en-US.png  화면_en-GB.png  화면_fr.png  화면_vi.png
  합성_ko.png  합성_ja.png  합성_zh-TW.png  합성_ms.png
  합성_en-US.png  합성_en-GB.png  합성_fr.png  합성_vi.png
  _작업/        ← 중간 파일(plate, render.py, content.py, 좌표). 결과물 아님
```

폴더가 이미 있고 다른 건의 결과가 들어 있으면 `YYYYMMDD_2` 로 만든다.

## 절대 규칙

- **이미지 생성 모델을 쓰지 않는다.** 기하 합성만 한다. 생성하면 화면 글자가 뭉개진다.
- **좌상단 통신사명은 전 언어에서 지운 채로 둔다.** 상태바 우측 아이콘(신호·와이파이·배터리)은 남긴다.
- **폰트는 새로 고르지 않는다.** 원본 화면이 어떤 폰트를 쓰든 `scripts/textkit.py` 의 세트를
  그대로 쓴다 (한국어=그리운 프롬솔 손글씨, 일본어=ShinRetroMaruGothic,
  번체·라틴·베트남어=ResourceHanRoundedCN, 시계 위 날짜 줄만 iOS 시스템 폰트).
  원본이 iOS 시스템 폰트로 되어 있어도 마찬가지다 — 시리즈 전체의 통일이 우선이다.
- **합성은 `--scale 3`.** 바탕 사진이 작으면 그냥 뽑을 때 잔글씨가 뭉갠다.
- **숫자·점수로 "됐습니다" 하지 않는다.** 아래 ⚠ 표시가 붙은 단계는 결과 그림을 직접 보고 넘어간다.
- 사용자는 디자이너다. 한국어로, 화면과 결과물의 말로 보고한다.

## 절차

도구는 전부 이 SKILL.md 옆 `scripts/` 에 있다. 아래 예시의 `scripts/` 는 그 절대경로로 읽는다.

### 0. 처음 쓰는 컴퓨터라면 (한 번만)
```bash
python3 scripts/doctor.py
```
폰트 6종·파이썬 패키지·swift 를 점검하고 빠진 것과 받는 곳을 알려 준다.
**폰트는 라이선스 때문에 같이 배포하지 못한다** — 각자 설치해야 한다.
하나라도 빠지면 글자가 네모로 나오거나 중간에 죽으니 여기서 걸러야 한다.
이미 돌려 본 컴퓨터면 건너뛴다.

### 1. 입력과 작업 폴더
이미지 2장의 경로를 확인한다. 한 장만 왔거나 어느 쪽인지 모호하면 그때만 물어본다.
`<결과폴더>/YYYYMMDD/_작업/` 을 만들고 원본 2장을 복사해 둔다.

### 2. 화면을 읽는다 ⚠
화면 이미지를 **직접 보고**(Read) 화면에 있는 글자를 전부 받아 적는다.
날짜 줄, 요일 헤더, 칩/뱃지, 제목, 부제, 섹션 라벨 — 빠뜨리면 그 자리만 원본 언어로 남는다.

같이 볼 것: **원본이 성한지.** 상태바 아이콘이 잘렸거나 정체 모를 도형이 붙어 있으면 원본 결함이다.
  8장 전부에 그대로 복사되니 plate 만들 때 같이 고친다(치이카와 건: 배터리 알약이 '68' 중간에서 잘려 있었다).

### 3. 문구를 8개 언어로 만든다
`content_template.py` 를 `_작업/content.py` 로 복사해 채운다.
- 날짜 줄과 요일 헤더는 **손으로 짓지 않는다.**
  `swift scripts/datecheck.swift <년> <월> <일>` 결과를 그대로 옮긴다 (CLDR = 실제 iOS 표기).
  ko 결과가 원본 스크린샷과 일치하는지 대조하면 날짜 자체가 맞는지도 검증된다.
- 앱이 만드는 문구(`9/14 (월)` 같은 섹션 라벨)는 iOS 규격이 아니므로 원본 꼴을 따라 번역한다.
- 폭이 고정된 칸(칩)은 12자를 넘기지 않게 줄여 쓴다.

### 4. 좌표를 잰다 ⚠
```
python3 scripts/measure.py _작업/화면.png
```
`화면_측정.png` 를 **직접 보고**(Read) 번호 붙은 박스를 의미에 연결한다.
캐릭터 그림에도 박스가 붙으니 그림을 봐야 글자 박스를 골라낼 수 있다.
박스의 **왼쪽 x · 세로중심 · 높이**가 그대로 render.py 상수가 된다.

### 5. 배경 판(plate)을 만든다 ⚠
지울 사각형 목록을 정해 인페인트한다. 글자보다 살짝 넉넉하게, 단 **남겨야 하는 것은 제외**한다
(불릿·체크 동그라미·아이콘). 통신사명 자리도 지움 목록에 넣는다.
```
python3 scripts/plate.py _작업/화면.png --rects "x0,y0,x1,y1; ..." --out _작업/plate.png
```
`plate_지운영역.png` 를 **보고** 글자 잔상이 없는지, 배경이 뭉개지지 않았는지 확인한다.

### 6. 8개 언어로 렌더한다 ⚠
`render_template.py` 를 `_작업/render.py` 로 복사해 4단계 좌표로 바꾸고,
화면 구조가 다르면 그리는 부분을 고친다.
render.py 는 작업 폴더에서 돌기 때문에 textkit 을 스스로 찾아야 한다.
템플릿 맨 위 `skill_scripts()` 블록을 그대로 두거나, 이 스킬 폴더의 `scripts/` 절대경로를
직접 적어도 된다.
```
cd _작업 && python3 render.py ..
```
8장을 가로로 이어 붙인 확인용 이미지를 만들어 **직접 본다.**
글자가 칸 밖으로 나가거나, 겹치거나, 네모(글리프 없음)로 나온 곳이 없어야 한다.
칩 글자가 언어별로 들쭉날쭉하면 `BOOSTS` 로 맞춘다 (가장 긴 글자가 칸 폭의 80~88%).

### 7. 사진에서 화면 네 귀퉁이를 잡는다 ⚠
```
python3 scripts/mockup.py --photo 사진.png --detect
python3 scripts/mockup.py --photo 사진.png --unwarp --screens <날짜폴더> --screen-prefix 화면_
```
`사진_역워프.png` 를 **직접 보고** 다이나믹 아일랜드와 하단 홈 인디케이터가
온전한 모양으로 펴졌는지 확인한다. **검출 성공·매칭 점수는 정합성의 증거가 아니다.**
(inliers 135가 나왔는데도 화면이 폰 밖으로 삐져나간 적이 있다.)
**네 변이 진짜 화면 경계에 붙었는지 반드시 검산한다.** 검출된 사각형은 보통 몇~십몇 px
안쪽이라, 그대로 합성하면 가장자리에 **옛 화면 색이 실오라기처럼 남는다**.
가장 확실한 방법은 **화면 영역을 밝기로 따서 네 변을 다시 피팅**하는 것이다
(어두운 베젤이 화면을 빙 둘러싸므로 가운데에서 이어진 밝은 덩어리 = 화면):

```python
g = cv2.cvtColor(cv2.imread('사진.png'), cv2.COLOR_BGR2GRAY)
n, lab, *_ = cv2.connectedComponentsWithStats((g > 50).astype('uint8'), 8)
comp = (lab == lab[int(cy), int(cx)]).astype('uint8')      # cx,cy = 기존 사각형 중심
c = max(cv2.findContours(comp, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_NONE)[0], key=cv2.contourArea)
newq = mockup.refine_quad(c, q)          # 모서리 원호를 빼고 네 변에 직선 피팅
```
임계값 40~70 에서 결과가 흔들리지 않으면 믿을 만하다.
그다음 여백 120px 을 두고 펼쳐 네 변의 밝기 꺾이는 자리를 찍어 **±2px 안**인지 확인한다.
(아래 변 가운데는 홈 인디케이터가 어두워서 잘못 읽히니 좌우 구간만 본다.)
어긋나면 `--grid` 로 격자를 얹어 좌표를 눈으로 읽고 `--quad` 로 직접 준다.
좌표는 `<사진>.quad.json` 에 저장되어 다음부터 자동으로 쓰인다.

### 8. 합성한다
```
python3 scripts/mockup.py --photo 사진.png --all --scale 3 \
  --screens <날짜폴더> --screen-prefix 화면_ --out-dir <날짜폴더> --out-prefix 합성_
```
`--edge` (기본 1.0) 는 화면 경계를 베젤 쪽으로 미는 양이다. 좌표가 맞는데도 가장자리에
옛 화면 색이 비치면 키운다. 마스크가 부드러워지는 구간에서 사진이 비치는 것을 막아 준다.

### 9. 확인하고 보고한다 ⚠
합성 8장을 이어 붙인 확인용 이미지와 100% 확대 crop을 **직접 보고** 넘긴다.
- 화면이 폰 밖으로 나가지 않았는지
- 잔글씨(날짜·마감 줄)가 뭉개지지 않았는지
- 언어별로 빠진 글자가 없는지
그런 다음 결과 폴더 경로와 파일 목록을 한국어로 짧게 보고한다. 결과가 별로면 솔직히 말한다.

## 화면 구조가 예시와 다를 때

화면 구조와 폰트가 다르면 `_작업/render.py` 는 새로 쓴다. 실제 예시 두 벌이 있다:
캘린더+할일·손글씨 = `render_template.py`, 두 개 위젯·iOS 시스템 폰트 = 20260908 치이카와 건.

`render_template.py` 는 캘린더+할일 화면(도라에몽 건)의 구조로 되어 있다.
다른 구조면 `textkit` 만 그대로 쓰고 그리는 부분을 새로 쓴다. textkit이 주는 것:
- `Ctx(loc, TARGETS, BOOSTS, date_ink, date_cy)` — 잉크 높이로 크기를 맞춘 로케일별 글자 스타일
- `draw_text(...)` — 잉크 왼쪽/가로중심 기준 배치, 폰트에 없는 글자만 폴백 폰트로 대체
- `uniform(...)` — 여러 줄을 한 크기로 통일 (줄마다 크기가 튀는 것 방지)
- `draw_date(...)` — 날짜 줄만 iOS 시스템 폰트, 전 언어 같은 크기·베이스라인
- `new_layer` / `flatten` — 2배로 그린 뒤 축소해 계단 없애기

자세한 실측값과 지난 건에서 걸러낸 실수는 `references/실측과-함정.md` 를 본다.
